# 삼국통일 FreeNet 런처

최신 로컬 빌드 버전: **1.3.3 (충돌 진단용)**

1.3.3은 GameMonitor.exe로 실행한 게임의 처리되지 않은 예외를 포착합니다.
runtime/crashes/crash-monitor.log에 실제 게임 PID, 예외 주소와 종료 코드를 기록하고
최소 덤프를 같은 폴더에 저장합니다. 진단 도우미의 정상 종료 및 의도적 오류 덤프 생성 테스트를 통과했습니다.
덤프에는 메모리 일부가 포함되므로 계정 DB처럼 보호하고 공개 업로드하지 마세요.
게임 파일이나 Windows 전역 오류 보고 설정은 변경하지 않습니다.
2026-09-18 00:04:36 맵 선택 중 충돌은 아직 원인이 확정되지 않았으며,
이 빌드는 그 충돌이 수정됐음을 의미하지 않습니다. 디버거 사용은 실행 타이밍에 영향을 줄 수 있습니다.

1.3.2는 E1/08 방 생성·갱신 요청에 응답하고 연결별 방 등록 정보를 유지합니다.
인증되지 않은 요청, 잘못된 형식, 다른 연결이 소유한 중복 이름은 거부합니다.
채널 복귀나 연결 종료 시 등록을 정리합니다. 방 비밀번호 및 요청 원문은 로그에 남기지 않습니다.
원본 게임의 성공 응답 처리(호스트 상태 4, 방 이름 복사, 생성창 닫기)를 에뮬레이션으로 검증했습니다.
실제 방 대기 화면 표시와 다른 PC의 참여·대전은 별도 검증이 필요합니다.

1.3.0은 계정 생성 성공값을 1로 수정하고, E1/28 서버 난수 → E1/36 사전 단계 →
E1/29 비밀번호 증명 검증 → E1/0B 채널 목록 응답을 구현합니다.
게임의 비표준 SHA-1 계산 결과와 클라이언트 성공 분기를 x86 에뮬레이션으로 검증했습니다.
기존 accounts.db의 두 필드를 합친 20바이트 검증값을 그대로 사용합니다.
계정 DB는 비밀번호와 동등하게 보호해야 하며 공유·업로드하지 마세요.

1.2.2는 실행용 게임 복사본의 송신 큐 추가·전송을 공통 잠금으로 직렬화합니다.
큐 항목이 완성되기 전에 송신 스레드가 읽는 경로를 x86 에뮬레이션으로 재현했습니다.
원본은 0x43ccbd에서 충돌하고 패치본은 같은 실행 순서에서 정상 전송했습니다.
실제 게임 로그인·멀티플레이 전체 성공 여부는 별도 확인이 필요합니다.
패치는 SHA-256으로 확인한 게임 버전에만 적용됩니다. 원본은 변경하지 않습니다.

`SamKook.exe`의 폐쇄된 인터넷 로비 주소 두 개를 실행용 복사본에서만 `127.0.0.1:7104`로 바꾸고 로컬 로비 서버를 함께 실행합니다. 원본 게임 파일은 변경하지 않습니다.

## 사용법

1. `SamKookLauncher.exe`를 실행합니다.
2. 게임 경로가 다르면 `찾기`에서 `SamKook.exe`를 선택합니다.
3. `게임 실행`을 누릅니다.
4. 게임에서 `함께하기 → 인터넷 플레이`로 들어갑니다.

### 두 PC 연결

- A PC: `접속 서버 IP`를 `127.0.0.1`로 두고 `로컬 서버 시작`을 누릅니다.
- B PC: `접속 서버 IP`에 A PC의 LAN, Radmin VPN 또는 Hamachi IPv4 주소를 입력하고 게임을 실행합니다.
- A PC의 방화벽과 공유기에서 TCP 7104 접근이 가능해야 합니다.
- `hosts 파일 열기` 버튼은 Windows hosts 파일을 메모장으로 엽니다. 저장에 관리자 권한이 필요할 수 있습니다.

현재 서버는 계정 인증, 채널 목록·입장 알림, 방 생성 승인을 제공하는 초기 호환 서버입니다. 사용자 목록, 채팅, 다른 PC의 방 조회·입장과 실제 대전은 아직 완성되지 않았습니다. 인터넷 공개 운영은 권장하지 않습니다.

### v1.3.1 진단 및 개선

- 2026-09-17 23:49 로그: 인증 성공 후 E1-0C 채널 입장 요청을 처리하지 않던 부분을 수정했습니다.
- 원본 게임의 E1-0F 이벤트 7 처리 경로에 맞춰 두 개의 NUL 종료 문자열을 전송합니다. 원본 코드 에뮬레이션 및 TCP 통합 테스트를 통과했습니다.
- 게임 PID와 종료 코드를 기록하고, 미지원 요청을 명시적으로 기록합니다.
- 최신 종료에 대응하는 Windows 충돌 기록이 없어 충돌 원인은 아직 확정하지 않았습니다. 실제 게임 재시험이 필요합니다.

접속 및 패킷 기록은 런처 폴더의 `freenet.log`에도 저장됩니다. 오류가 생기면 이 파일을 확인합니다.

계정 생성과 로그인을 지원합니다. 계정 정보는 `accounts.db`에 저장되며 게임이 생성한 비밀번호 검증값만 기록하고 입력한 비밀번호 평문은 저장하지 않습니다.
동일한 계정 생성 요청이 재전송되면 같은 비밀번호일 때 성공으로 처리하고, 다른 비밀번호일 때만 중복 계정으로 거부합니다.

## 런처 업데이트 배포

`런처 업데이트` 버튼은 TLS 1.2로 GitHub Releases를 먼저 확인하고, Release가 없으면 저장소의 `update.json`을 확인합니다. 새 버전 ZIP을 내려받아 런처 종료 후 교체하고 자동으로 다시 실행합니다.

## 빌드

PowerShell에서 `build.ps1`을 실행합니다. Windows에 포함된 .NET Framework C# 컴파일러를 사용하므로 별도 SDK가 필요 없습니다.
