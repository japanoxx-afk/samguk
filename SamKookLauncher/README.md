# 삼국통일 FreeNet 런처

최신 버전: **1.6.0 (맵 미니맵 프리뷰)**

## 맵 미니맵 프리뷰

- 런처의 `맵 미니맵 프리뷰`에서 `Mission` 폴더의 SKM 맵 목록과 지형 구조를 확인할 수 있습니다.
- `P32M` 서명·크기·지형 타일 범위를 검증하며, 손상된 맵은 오류로 표시합니다.
- 현재 프리뷰는 지형 타일 ID를 색상으로 요약한 구조도입니다. 게임의 실제 미니맵 팔레트와 오브젝트는 완전히 재현하지 않습니다.

## 12부대 선택 제한 검토

`SamKook.exe`의 선택 제한은 하나의 숫자만 바꾸는 구조로 확인되지 않았습니다. 선택 목록, UI 슬롯, 명령 패킷의 고정 크기가 연결되어 있어 일부 비교값만 늘리면 메모리 손상·명령 누락·멀티 동기화 오류가 발생할 수 있습니다. v1.6.0에서는 안전하게 검증할 수 없어 선택 수를 변경하지 않았습니다.

- `멀티 저지연`은 원본의 명령 버퍼 기준 0/2/4/6을 0/0/1/2로 줄이고, 멀티 동기화 검사 주기를 6프레임에서 3프레임으로 줄입니다.
- A·B PC 모두 v1.5.0의 같은 설정으로 실행해야 합니다. 동기화 풀림이나 끊김이 발생하면 둘 다 옵션을 해제하고 재실행하세요.
- `송신 스레드 CPU 점유 완화`는 반복문에서 고정 1ms 대기 대신 나머지 타임 슬라이스만 양보하도록 변경했습니다.
- 원본 `SamKook.exe`는 변경하지 않고 `runtime`의 실행용 복사본에만 패치합니다.

- Alt+Enter는 창모드와 테두리 없는 전체화면 사이를 전환합니다.
- 창모드와 테두리 없는 전체화면은 GDI 호환 렌더러, 전체 다시 그리기 및 자식 창 다시 그리기를 사용합니다. 로그인 화면 깨짐 완화를 위한 설정이며 실제 게임 화면에서 해결 여부는 아직 확인하지 못했습니다. GDI는 GPU 렌더링보다 CPU 사용량이 늘 수 있습니다.
- 게임을 종료한 뒤 런처 업데이트를 적용하고 다시 실행해야 새 설정이 생성됩니다. 원래 전체화면 모드는 변경하지 않습니다.

## 화면 및 실행 옵션

- `창모드` 또는 `테두리 없는 전체화면` 선택 후 게임을 다시 실행하세요. 원래 전체화면으로 되돌릴 수도 있습니다.
- `16:9 늘려 표시`는 기존 4:3 화면을 가로로 늘리는 기능입니다. 지도 시야 확장이나 엔진 해상도 변경이 아닙니다. 체크 해제 시 4:3을 유지합니다.
- 창 크기는 모니터 작업 영역에 맞춰 최대 높이 720으로 제한합니다. Alt+Enter로 모드를 전환할 수 있습니다.
- cnc-ddraw 7.1.0.0(MIT)을 포함하며 실행용 복사본 옆에만 설치합니다. 원본 게임 EXE와 DLL은 변경하지 않습니다.
- 신규 화면 설정은 호환 모듈 설정 생성·해시 검증까지 테스트했습니다. 실제 게임 화면, 마우스 위치, 맵 선택창은 사용자 PC에서 확인이 필요합니다.

## 네트워크 입력 지연 조사와 적용 범위

게임의 실제 대전 명령은 DirectPlay Send/Receive 경로(0x43974A/0x439CDF 등)를 사용합니다.
로비 TCP 서버는 방 검색과 채팅용이므로 이것만 최적화해서 대전 명령 지연을 해결할 수는 없습니다.
0x439EB9의 2000ms는 누락된 동기화 응답을 기다리는 중의 처리 기준이고,
게임 턴 간격에는 30~50ms 조절 코드가 있습니다. 이것들을 근거 없이 줄이거나 제거하지 않았습니다.

- `송신 스레드 CPU 점유 완화`: 0x44A1A0의 무대기 반복마다 Sleep(1)을 요청합니다. 실제 대기 시간은 Windows 타이머에 따라 더 길 수 있습니다. 레지스터·플래그·스택 보존 및 기존 큐 패치를 에뮬레이션으로 검증했습니다. 문제가 생기면 체크를 해제하고 다시 실행하세요.
- 일반 실행은 디버거를 붙이지 않습니다. 충돌 조사 때만 `충돌 진단 모드`를 켜세요.
- 화면 모듈은 VSync를 끄고 단일 CPU 강제 고정을 사용하지 않으며 자체 게임 틱 제한을 끕니다. 출력은 60fps로 제한하지만 게임 시뮬레이션 속도는 변경하지 않습니다.
- `네트워크 지연 측정`은 입력된 서버 IP까지 ICMP 5회 최소/평균/최대 및 응답 수를 기록합니다. 실제 DirectPlay 왕복 시간과 같지 않으며 ICMP 차단을 패킷 손실로 단정할 수 없습니다.

**약 1초 명령 지연의 원인 및 개선 폭은 아직 실측으로 확정하지 못했습니다.**
B PC에서 26.157.67.215까지 측정하고, 양쪽 모두 같은 버전으로 같은 LAN/VPN 환경에서 비교하세요.
한 PC 자신에게 ping한 결과는 원격 지연 진단에 도움이 되지 않습니다. VPN 경로/손실/느린 참가자도 확인해야 합니다.

화면 모듈, 라이선스, 실행 파일, 업데이트 도우미는 모두 업데이트 ZIP에 포함됩니다.
화면·성능 설정 파일과 계정 DB는 업데이트 시 덮어쓰지 않습니다. `package.ps1`이 배포 파일 목록과 모듈 해시를 확인합니다.
업데이트의 새 모듈 포함, 필수 파일 누락 거부, 정상 재시작과 실패 복구를 테스트합니다.
cnc-ddraw 출처 및 설정: https://github.com/FunkyFr3sh/cnc-ddraw/tree/v7.1.0.0 (세부 해시는 vendor/cnc-ddraw/PROVENANCE.md).

## 기존 로비 기능

기본 접속 서버 IP: `26.157.67.215`. 기존 설치의 저장된 IP는 보존하므로 필요하면
B PC의 접속 서버 IP를 직접 변경하세요. A PC에서는 먼저 `로컬 서버 시작`을 누릅니다.
E1/09 방 조회에 최대 20개의 공개 방과 방장 IP·맵 정보를 반환합니다.
E1/0E 로비 채팅을 E1/0F 이벤트 5로 변환해 인증된 로비 사용자에게 전달합니다.
한글(CP949) 채팅을 지원하고 입력 길이를 제한하며 채팅 내용은 로그에 기록하지 않습니다.
채팅방 나가기(E1/10)는 방을 유지하고, 광고 종료(E1/02)·채널 복귀·접속 종료는 방을 제거합니다.
두 TCP 클라이언트로 조회·삭제·양방향 한글 채팅을 검증했고, 실제 응답을 원본 게임 코드에
입력해 방 이름/맵/방장 IP 처리 및 채팅 표시 경로를 에뮬레이션했습니다.
실제 두 PC의 게임 화면과 방 참여·대전은 아직 검증되지 않았습니다.
비밀번호 방은 비밀번호 노출을 방지하기 위해 목록에서 제외합니다. 우선 비밀번호 없이 테스트하세요.

## 사용법

1. `SamKookLauncher.exe`를 실행합니다.
2. 게임 경로가 다르면 `찾기`에서 `SamKook.exe`를 선택합니다.
3. `게임 실행`을 누릅니다.
4. 게임에서 `함께하기 → 인터넷 플레이`로 들어갑니다.

### 두 PC 연결

- A PC: `접속 서버 IP`를 `127.0.0.1`로 두고 `로컬 서버 시작`을 누릅니다.
- B PC: `접속 서버 IP`에 A PC의 LAN, Radmin VPN 또는 Hamachi IPv4 주소를 입력하고 게임을 실행합니다.
- A PC의 방화벽과 공유기에서 TCP 7104 접근이 가능해야 합니다.
- `hosts 파일 열기` 버튼은 Windows hosts 파일을 메모장으로 엽니다. 저장에 관리자 권한이 필요할 수 있습니다.

현재 서버는 계정 인증, 채널 입장, 방 생성·조회 및 로비 채팅을 제공하는 초기 호환 서버입니다. 사용자 목록과 비밀번호 방 참여는 미구현이며 실제 방 참여·대전은 검증되지 않았습니다. 인터넷 공개 운영은 권장하지 않습니다.

접속 및 패킷 기록은 런처 폴더의 `freenet.log`에도 저장됩니다. 오류가 생기면 이 파일을 확인합니다.

계정 생성과 로그인을 지원합니다. 계정 정보는 `accounts.db`에 저장되며 게임이 생성한 비밀번호 검증값만 기록하고 입력한 비밀번호 평문은 저장하지 않습니다.
동일한 계정 생성 요청이 재전송되면 같은 비밀번호일 때 성공으로 처리하고, 다른 비밀번호일 때만 중복 계정으로 거부합니다.

## 런처 업데이트 배포

`런처 업데이트` 버튼은 TLS 1.2로 GitHub Releases를 먼저 확인하고, Release가 없으면 저장소의 `update.json`을 확인합니다. 새 버전 ZIP을 내려받아 런처 종료 후 교체하고 자동으로 다시 실행합니다.

## 빌드

PowerShell에서 `build.ps1`을 실행합니다. Windows에 포함된 .NET Framework C# 컴파일러를 사용하므로 별도 SDK가 필요 없습니다.
